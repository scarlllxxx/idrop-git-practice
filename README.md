# IDrop — сервис по скинам CS2

IDrop — платформа для покупки, продажи и обмена скинами CS2.
Прямые конкуренты: Case-battle, TopSkin, Keyser, Upgrader.

## Описание проекта
Сервис предоставляет пользователям возможность:
- покупать скины;
- продавать свои предметы;
- участвовать в кейс-баттлах;
- отслеживать рыночные цены.

## Стек (планируемый)
- Backend: Node.js / Python
- Frontend: React
- БД: PostgreSQL
- Инфраструктура: Docker, Docker Compose
